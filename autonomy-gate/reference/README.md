# Decision References

These files supply the Gate's scoring criteria, risk vocabulary, surface constraints, precedents, and artifact structures. They are runtime knowledge, not a reading sequence for first-time users.

- `autonomy-criteria.md` defines the four scoring dimensions and maturity ladder.
- `risk-classification.md` defines risk levels and named failure patterns.
- `surface-capability-matrix.md` bounds what each execution surface can do.
- `precedents.md` records external governance precedents behind the architecture.
- `templates/` contains model-facing artifact structures.

For normal use, upload the files through the manifest in the parent `README.md` and interact with the Gate. Do not edit these files per workflow.
