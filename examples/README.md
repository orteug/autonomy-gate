# Committed Receipts

This folder contains finished Gate outputs that can be inspected without installing or running the operator.

[`trial-audit-output.md`](trial-audit-output.md) demonstrates three materially different outcomes:

1. A hard refusal for a vendor bank-account change.
2. A supervised candidate-screening workflow.
3. An autonomous weekly KPI workflow.

Use these receipts to judge output quality and mechanism traceability. Use `JUDGE_GUIDE.md` at repository root to run falsifiable tests against the live operator.
