# Committed Receipts

This folder contains finished Gate outputs that can be inspected without installing or running the operator. The canonical release receipts are in `receipts/` and are validated by `testing/run_release_suite.py`.

The `receipts/` directory demonstrates three materially different outcomes using the canonical packet, handoff, and disposition contracts:

1. An autonomous weekly KPI workflow promoted to `BUILD_READY` (`01-autonomous-project.md`).
2. A supervised refund workflow blocked on organizational evidence (`02-supervised-refund.md`).
3. A hard `GATE-2` refusal of a vendor bank-account change (`03-human-only-bank-change.md`).

`trial-audit-output.md` is retained as historical competition evidence and may use earlier terminology. Use the canonical receipts for current contract review.
