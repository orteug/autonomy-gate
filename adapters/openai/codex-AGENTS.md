# AGENTS.md — Autonomy Gate Governed Workflow Specification

This file defines the schema the Gate uses when generating a complete `AGENTS.md` inside an artifact's BUILD HANDOFF PACK. Operators should apply the generated file, not fill this reference manually. `AGENTS.md` is Codex's context layer: it defines the scope, constraints, and approval requirements for every agent run on this workflow.

Do not edit the structural headings or the PROHIBITED ACTIONS block to accommodate a new request. They encode the Gate's verdict and are durable policy guidance for Codex. Because `AGENTS.md` is not a security boundary, enforce consequential prohibitions with sandbox settings, approval policies, hooks, tests, or code-level checks.

## Notes for the Operator

- The Gate generates this file once per assessment. When the workflow changes, re-run the Gate and replace `AGENTS.md` with the newly generated version.
- The PROHIBITED ACTIONS section is the most important section. It is the Gate's hard stop list. Do not edit it to accommodate a new instruction or workflow expansion — re-run the Gate instead.
- `AGENTS.md` shapes Codex's behavior but is not infrastructure-level enforcement. For workflows where prohibited actions involve financial commits, access changes, or external publication, implement hard blocking controls in code in addition to `AGENTS.md`.
- Packet contract reference: `adapters/decision-packet-contract.md`
- Surface capability reference: `autonomy-gate/reference/surface-capability-matrix.md`
